О проекте

Данный сайт является дипломной работой студента 3 курса направления "Веб-дизайн" в академии НАДИП. Проект демонстрирует возможности кастомизации пользовательского интерфейса в реальном времени.

Функциональность

На сайте реализованы следующие возможности:

  • Изменение цветовой схемы интерфейса
  • Включение/выключение детского режима
  • Изменение стиля курсора мыши
  • Адаптивный дизайн для различных устройств

Технологии

При разработке использовались:

  • HTML5 для структуры сайта
  • CSS3 для стилизации и анимаций
  • JavaScript для интерактивности
  • CSS переменные для динамического изменения стилей

Программы для веб-дизайна

Figma

Figma — это облачный редактор для совместной работы над интерфейсами, прототипами и дизайн-системами.

  • Совместная работа в реальном времени
  • Авто-макеты (Auto Layout)
  • Компоненты и стили
  • Интерактивные прототипы
  • Плагины и интеграции
  • Векторные сети (Vector Networks)

Adobe XD

Adobe XD — инструмент для проектирования пользовательских интерфейсов и создания прототипов от Adobe.

  • Повторяющиеся сетки (Repeat Grid)
  • Голосовые прототипы
  • Авто-анимация
  • Интеграция с Creative Cloud
  • Совместная работа
  • Плагины и расширения

Sketch

Sketch — векторный графический редактор для дизайнеров интерфейсов и экранного дизайна.

  • Символы и переопределения
  • Библиотеки символов
  • Векторное редактирование
  • Экспорт кода
  • Прототипирование
  • Большое сообщество и плагины

Программы для 3D-графики

Blender

Blender — бесплатное программное обеспечение для создания трёхмерной компьютерной графики.

  • Моделирование, скульптинг и текстурирование
  • Анимация и риггинг
  • Визуализация (рендеринг)
  • Композитинг и видеомонтаж
  • Симуляции (физика, жидкости, ткани)
  • Полностью бесплатный и с открытым исходным кодом

Cinema 4D

Cinema 4D — профессиональная программа для создания трёхмерной графики и анимации.

  • Мощное моделирование
  • Продвинутая анимация
  • Динамика и симуляции
  • Интеграция с Adobe After Effects
  • Модульная система
  • BodyPaint 3D для текстур

3ds

3ds — программное обеспечение для 3D-моделирования, анимации и визуализации от Autodesk.

  • Полигональное моделирование
  • Средства анимации
  • Арнольд рендерер
  • Инструменты для архитектурной визуализации
  • Динамика и симуляции
  • Поддержка скриптинга

Другие программы для дизайна

Adobe Photoshop

Мощный редактор растровой графики для обработки фотографий и создания цифровых изображений.

  • Расширенные инструменты ретуши
  • Работа со слоями и масками
  • Фильтры и эффекты
  • Типографика и текст
  • Поддержка 3D-объектов
  • Интеграция с другими продуктами Adobe

Adobe Illustrator

Профессиональный редактор векторной графики для создания логотипов, иконок и иллюстраций.

  • Точное векторное редактирование
  • Инструменты для типографики
  • Градиенты и прозрачность
  • Работа с кистями и символами
  • Эффекты и стили
  • Экспорт в различные форматы

Affinity Designer

Мощный векторный графический редактор от Serif с поддержкой растровых кистей.

  • Гибридный векторно-растровый workflow
  • Высокая производительность
  • Точные инструменты векторного редактирования
  • Поддержка PANTONE® и ICC-профилей
  • Экспорт в SVG, PDF, EPS и другие форматы
  • Доступная цена без подписки
